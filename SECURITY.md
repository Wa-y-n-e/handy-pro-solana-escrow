# Security and disclosure scope

This is a **public verification companion**, not a mirror or source release of the Handy Pro application.

## Never publish here

- Any code copied from the private Handy Pro application or production services
- The deployed Anchor escrow program's proprietary source code
- Private or seed keys, wallet keypairs, signing credentials, access tokens
- `.env` files, database exports, service-role secrets, internal URLs or credentials
- User data, payment identifiers, logs containing customer information
- Deployment authorities, CI/CD tokens or unreleased infrastructure details

The public program address and the cited deployment transaction are independently visible on Solana Devnet. Their publication does not disclose wallet secrets.

## What is included

- Publicly disclosed project identity, website and Solana Devnet program address
- A newly written, read-only script that uses public JSON-RPC calls
- This documentation

This repository **does not** establish the equivalence of its contents to the deployed program binary, and it does **not** prove that the whole Handy Pro service is open source. Review the event's submission rules before presenting this as a qualifying open-source entry.

If you discover a security concern, contact the maintainer privately; do not post tokens, private keys or exploitable details in a public issue.
